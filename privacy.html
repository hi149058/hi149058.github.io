Privacy Policy

Last updated October 4, 2026

Frisk is a personal assistant that runs on its owner's Mac and connects only to the owner's own Google account. It has no other users, no servers of its own, and no advertising. This page explains what it accesses and why.

Google data Frisk accesses

  • Google Tasks: read, add, update and complete tasks.
  • Google Calendar: read events and add new ones.
  • Gmail: read-only, to point out emails that need a reply. Frisk cannot send, delete or change email.
  • Google Docs: create new documents, edit only documents Frisk created, and read the owner's documents when asked. Frisk cannot edit or delete documents it didn't create.
  • Google Drive file names: to find a document by its title. Frisk does not read the contents of other Drive files.

How the data is used

Google data is used only to answer the owner's own requests: listing what's due, adding tasks and events, and writing or reading documents. When the owner asks a question, the relevant data is sent to Anthropic's Claude API to generate the answer. It is not sold, shared with anyone else, or used for advertising, and it is not used to train AI models.

Storage

Login tokens and short-lived conversation history are stored only on the owner's Mac. Voice audio is processed on the Mac and is not uploaded. Screenshots are taken only when the owner asks about their screen or starts a recording, stay on the Mac, and are sent to the Claude API only as part of that request.

Google API Services User Data Policy

Frisk's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Account → Third-party connections. Deleting Frisk's folder on the Mac deletes everything it stored.
